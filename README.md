# Stop-Ball
Landing page responsiva da Stop Ball, uma marca de produtos esportivos, desenvolvida com HTML, CSS e JavaScript. O projeto apresenta produtos, tecnologias, depoimentos e outras seções da marca, com interações e animações.

# Stop Ball

**Vestindo sua paixão!**

O Stop Ball é um projeto de desenvolvimento web inspirado no universo do futebol e na paixão pelo esporte. O site apresenta a identidade da marca Stop Ball, voltada para quem vive o futebol dentro e fora de campo.

## Sobre o projeto

O objetivo do projeto é desenvolver uma experiência digital moderna, visualmente atrativa e responsiva, valorizando os produtos, a identidade visual e a conexão entre a marca e os apaixonados por futebol.

## Funcionalidades

- Design moderno inspirado no futebol
- Layout responsivo para diferentes dispositivos
- Apresentação de produtos esportivos
- Seção de personalidades e jogadores famosos
- Navegação intuitiva
- Elementos visuais e animações para melhorar a experiência do usuário

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo

Este projeto faz parte do meu aprendizado em desenvolvimento web, com foco na criação de interfaces, responsividade, organização de código e desenvolvimento de experiências interativas.
