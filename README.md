# Stop Ball

Landing page desenvolvida para a Stop Ball, uma marca voltada ao segmento esportivo. O projeto apresenta a identidade da marca, seus produtos, tecnologias e diferenciais por meio de uma interface moderna e responsiva.

## Sobre o projeto

O Stop Ball foi desenvolvido como um projeto de desenvolvimento web, com o objetivo de criar uma experiência visual atrativa e facilitar a navegação dos visitantes pelo conteúdo da marca.

A página reúne diferentes seções para apresentar os produtos, destacar suas características e transmitir a proposta da empresa.

## Funcionalidades

- Layout responsivo para diferentes tamanhos de tela.
- Menu de navegação adaptado para dispositivos móveis.
- Navegação suave entre as seções.
- Animações de entrada dos elementos durante a rolagem.
- FAQ com perguntas e respostas.
- Carrosséis e banners.
- Efeitos visuais na navegação e nos elementos da página.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
